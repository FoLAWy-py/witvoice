# 05 · UI、交互与视觉验收

## 1. 视觉定位

桌面音频工具，不是网页后台仪表盘。桌面壳统一，主页面围绕“输入 → 处理设备 → 音色 → 虚拟麦克风”路由展示。

默认深色、一个克制强调色、稳定排版、清晰状态与大号Mute；同时完成浅色主题。不做满屏发光频谱、无目的毛玻璃和持续GPU动画。图标只使用一种有明确许可的图标集。

产品暂用中性名称“Voice Changer”，禁止从其他项目复制品牌、域名、账号和业务文案。

## 2. 信息架构

主导航只有：控制台、音色、设备与连接、诊断、设置。

控制台：当前输入与电平、处理设备、本地/远端标签、当前音色、虚拟输出目标、唯一主要Start/Stop、随时可用Mute。显示网络RTT和推理耗时要有不同标签；总延迟有`测得/估算/不可用`来源标识。

音色：空状态、导入参考、授权说明、解析、创建进度、试听、兼容性、删除。音色不可用时不让Start产生虚假Running状态。

设备与连接：物理输入、虚拟线输出、第三方应用应选择的输入名称、监听输出、附近计算设备、双向配对导入、信任撤销。配对设备不等于正在发送麦克风，必须分别显示。

诊断：backend/实际模型、设备格式、队列占用、RTF、p50/p95/p99、underflow、drop、networkloss、RAM/VRAM/CPU来源、脱敏导出。

设置：主题、语言文案架构、隐私/录音保留、资产位置、远端计算开关、退出行为。默认中文文案，本轮不要求完整多语言翻译，但所有用户文案集中管理。

## 3. 组件化

共享基元：Button、Dialog、Select、Slider、Switch、Tooltip、Tabs、Toast、Alert、EmptyState。
共享业务组件：DeviceSelector、VoiceCard、ProcessingRoute、SessionControls、StatusBadge、AudioMeter、MetricValue、PairingIdentityDialog、PermissionGuide、FailureBanner。

feature 内部维护页面状态；引擎/session状态来自Node单一权威源。不把关键安全判断只写在disabled按钮上；Node再验证一次。

首次建UI时用确定性的mock service做视觉测试，但显著标记开发模式。生产client只能连接真实Node；不能在连接失败时自动回退到mock数据。

## 4. 关键交互

- 首次启动：检查权限/虚拟设备/模型，并明确哪些操作需要用户确认；没有准备好只允许查看和修复，不能“开始后再报错”。
- 远端计算：展示即将发送的麦克风数据、profile数据和设备名/身份；默认不缓存原始音色。
- 输入/音色/节点切换：说明短暂静音；完成后显示实际生效配置。
- 断网/OOM/设备移除：显著“已静音，原声没有发送”；恢复按钮与具体原因；不能只弹一个toast然后继续绿色Running。
- 窗口关闭：托盘继续运行与退出停止明确分开；在继续运行前说明；退出后不留下麦克风采集或network listener。
- Mute：键盘和鼠标可到达，在加载/错误/失焦期间仍能执行。全局热键是可选项，本轮不把系统级热键安装当必需。

## 5. 可访问性与性能预算

所有功能可通过Tab/Shift-Tab和Enter/Space操作；焦点可见；模态框正确管理焦点；颜色不是唯一状态信号。

普通正文目标对比度≥4.5:1；交互目标≥32×32CSS px；正文默认≥14px；尊重reduced-motion。窗口最小1024×680，在125%、150%、200%系统缩放和1280×800逻辑布局下不截断关键控件；不足时使用滚动，而不是把主文字缩到不可读。

meter更新10Hz；诊断统计最多2Hz；频谱为非必需，禁止为了装饰把PCM发给WebView。数值动画不能影响真实状态更新时间。

## 6. HCI验收材料

hci 在写大量界面前提交 `docs/design/interaction-map.md`、`tokens.md`、`states.md`；frontend实现后提交实际桌面截图，而不是只提供设计草图。

至少包含：首次空状态、准备完成、本地运行、远端运行、模型未安装、虚拟设备缺失、信任失败、断网静音、切换音色、删除确认、键盘焦点、浅/深色。

独立HCI复核逐项给PASS/FAIL并列问题；不得用“看起来现代/漂亮”代替可核对结果。用户的音色试听与设计接受度可记录显式签收；没有签收不得伪造用户满意。

桌面E2E应使用实际Tauri窗口。Tauri官方目前提供WebdriverIO服务路线；浏览器mock测试仍只证明renderer部分。测试用嵌入driver/命令mock必须在发行构建禁用。[S04]
