# 06 · 权限、隐私、安装与交付

## 1. 权限策略

应用和Node使用普通用户权限。Codex也不得为了测试顺利而关闭安全软件、防火墙、Secure Boot、系统签名验证，或全局开启危险权限。需要安装驱动、改系统权限、申请签名证书或访问用户录音时，提出精确一次性操作与理由。

Tauri capabilities按窗口最小化；UI不能传任意shell命令、任意文件路径、任意模型模块名给Rust执行。本地IPC路径仅在私有目录，消息鉴权与长度限制并用；“同一用户SID”不是对本机所有恶意同用户进程的完全防护，文档不得夸大。

网络计算默认关闭；只与用户配对的节点交互。任何远端请求都没有启用本机物理麦克风的权限。

## 2. 资产与模型安装

从已审核manifest和固定来源安装选定引擎。明确显示下载总量、来源、版本、许可与磁盘空间，用户批准后才下载。训练、付费API、外网上传不在授权范围。

SHA-256只验证文件是否与manifest一致，不验证manifest本身可信。manifest需要由应用内可信签名/发行来源链绑定；测试manifest使用独立测试key且发行构建不能信任它。

流程：下载到临时目录 → 大小/摘要/格式校验 → 安全解包（防路径穿越、链接逃逸和解压炸弹）→ 原子移动至内容寻址目录 → 更新active指针。失败保留原可用版本。

本轮无自动App Updater和Driver Updater；提供版本化完整内部安装包。用户显式操作的引擎资产安装为必需，避免引入自动更新服务和签名运维扩张。

不加载用户拖入的`.pth/.pt/.pkl`、pickle或脚本。确有上游可信checkpoint格式要求时，只接受锁定来源和摘要，记录反序列化风险；下载后放worker，不在高权限进程反序列化。

## 3. 数据目录

Windows 使用按用户标准AppData目录；Mac使用Application Support/Cache/Logs/Keychain对应能力。路径通过平台API取得，不硬编码用户名。仓库不含用户私钥、录音、生成音频、模型权重或个人设备身份。

SQLite存metadata和设置，秘密通过OS保护。迁移前备份；失败显示恢复选项，不删除数据库重新来过。

诊断导出默认包含匿名化设备标识、版本、计数器、错误码、摘要、运行配置；不包含PCM、参考音频、私钥、完整token、原始用户路径。导出前预览字段。

## 4. 虚拟设备与再分发边界

用户可从官方渠道安装虚拟音频线并独立运行；本项目提供检测和路由向导。应用安装包不包含第三方驱动，不自动提升权限替用户安装，不改名冒充本产品原生设备。

VB-CABLE的官方页面说明了虚拟线方向与安装要求；BlackHole官方提供应用间路由，并有自身许可/商业集成说明。[S10][S11]

不因“开源”或“外部安装”就给出法律合规保证。若将来捆绑、修改、链接或公开商业发布，重新审核代码、权重、依赖、驱动与素材许可；不可在本轮靠删LICENSE规避问题。

## 5. 安装包与系统保护

M5必须构建Windows内部安装包和独立Node/worker布局，能在无开发环境的验收用户配置下安装、启动、停止、卸载。首次引擎安装后断开互联网仍可本地/局域网运行。

M6必须在Mac上构建并验证Apple Silicon应用与worker，不把Windows交叉编译日志当Mac硬件证据。需要实际的麦克风/局域网权限测试；计算节点模式应证明无需打开其麦克风。

内部包签名状态要显式报告：有合法签名材料则使用；没有则标为内部未公证/未签名产物及其安装限制，不绕过OS安全，也不称“面向公众即装即用”。若OS阻止真实安装且无法合法继续，对应验收BLOCKED。

公共发行、代码签名采购、Apple公证/商店提交、自研驱动与商业再分发授权属于另外的明确变更，不是本轮隐藏未完成任务。

## 6. 威胁与测试

必须测试：未授权peer、重放旧epoch、伪造descriptor、超长控制包、错误PCM长度、恶意profile路径、损坏manifest、签名不匹配、半下载、SQLite迁移中断、未知证书、误配置输出至物理设备、日志泄漏、退出后后台录音。

本轮不承诺抵御已经获得管理员权限的攻击者或完整被控的同用户桌面；但必须避免自身引入不必要的执行入口。
