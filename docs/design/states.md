# T021 权威状态与视图覆盖

枚举取Rust schema SessionState。下表规定展示与动作意图，实际可执行性/状态变化由Node验证。没有音频/worker资源的当前Node不能走Ready/Running。所有采集、传输、输出三个状态分开显示，单一SessionState不证明是否采集/发送。

| Node state | 中文主状态 | 主要动作意图 | 必须说明 |
|---|---|---|---|
| Idle | 闲置 | 满足输入/音色/路由条件后准备；Mute、退出可达 | 不显示正在变声。未知设备/模型能力不填示例数值。 |
| Preparing | 准备中 | 取消准备/Stop；Mute可达 | 不启动源麦克风采集或媒体传输；profile条件可在单独授权后按Prepare流程预传。阶段仅来自Node，无真实进度不显示假百分比。 |
| Ready | 准备完成 | 明确Start；更改配置重新准备；Mute可达 | 准备不等于开麦；输出位置、节点、音色实际摘要可见。 |
| Running | 运行中 | Stop、Mute；切换先经Node静音/重置 | 显示本地/远端与当前真实配置，不由按钮点击自行进入。 |
| Stopping | 停止中 | Mute保持可达；不再Start | 已发起停止不等于资源已释放，等待Node。 |
| Error | 准备失败 | 查看具体原因；Node允许Stop后重新Prepare | 冻结转换无直接Reset入口，UI不发明恢复路径，不自动重试开麦。 |
| Blocked | 条件未满足 | 定位缺少模型/虚拟端点/权限/音色；Stop后重准备 | 展示可操作修复，无准备条件不能Start。 |
| Degraded | 性能下降 | Mute、Stop；显示真实丢帧/队列/原因 | 仍可能有输出，不写“已静音”；恢复以Node确认资源为准。 |
| FailedMuted | 故障静音 | Stop；用户重试触发重新准备，不自动Start | Node确认输出失效才显示故障静音；单此状态不证明停止采集/网络发送。原声隔离保证必须来自实际Node治理证据。 |
| Muted | 已静音 | 明确取消静音、Stop | 取消静音要新epoch/资源校验并等待Node；旧buffer不回放。采集/传输状态另按真实Node数据展示。 |

连接标记独立于SessionState：connecting、connected、disconnected、unsupported。断开时显示“与节点连接中断，当前静音和采集状态无法确认”，最后状态带过期时间、取消绿色强调；Start/Unmute禁用，控制命令不进入离线待执行队列。重连请求实际状态/上下文，不重放旧Start/旧epoch。不能把断连变成前端自造FailedMuted。未知枚举显示“状态无法识别”并停止开启操作，保留兼容诊断。

| 额外视图 | 具体覆盖/行为 |
|---|---|
| 首次空状态 | 音色0条、模型未安装、虚拟路由未验证各有真实修复入口；不伪装样例音色/peer。 |
| 本地/远端运行 | 路由标签与处理设备身份不同；总延迟边界/来源可见；采集与profile传输授权分开。 |
| busy/信任失败 | Busy说明哪个实际资源不可用；错指纹/未知证书/撤销不显示临时可信或降级连接。 |
| 断网/设备移除/OOM | Node确认FailedMuted时常驻FailureBanner；IPC不可达显示未知；不默默切设备、音色、backend或原声。 |
| 切换音色/输入/节点 | 提示短暂静音，等待实际新配置/epoch确认再显示生效；失败保留静音和原因。 |
| 删除确认/导出预览 | 给明确对象/当前会话影响；可取消；诊断字段预览不含原始媒体/secret。 |
| 键盘焦点/深浅主题 | 同一状态两主题；文字与焦点均可辨，不用颜色单独编码。 |

状态截图矩阵：首次空、Ready、本地Running、远端Running、模型未装、虚拟路由缺失、信任失败、断网静音/连接未知两种、切换音色、删除确认、键盘焦点，均需后续实际Tauri与深浅主题产物；125/150/200%缩放下检查。当前全部NOT_RUN，不以本表作为T029签收。
