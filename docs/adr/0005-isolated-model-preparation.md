# ADR0005: isolate fixed model preparation from the worker control interpreter
Status: implementation in progress; no model/VC approval.
Evidence: warmup-stage-once7d failed heartbeat_read/504ms lastACK/404ms request; lastprogress model_load before, no after. This does not prove GIL or precise loader cause. Shared control/model Python threads cannot isolate interpreter-wide native stalls; target one bounded preparechild, same model/runtime and same Node-owned Job. No new engine/driver/service or threadarchitecture claim of actual success.
Parent Python authenticates Node control/media channels and keepsboundedcontrol; onechild alone owns the fixed model and model resources. Anonymous length-limited scalar prepare IPC, no pickle/token/raw logs, childmodel stdout/stderrNUL. Stop ack is not resource release; Node terminates/queryJob actualzero.
