# Repository operating rules

本项目是独立的Windows优先、Windows↔Mac LAN实时语音变声器。禁止引入其他项目业务。`docs/SPEC.md`是需求基线；`docs/PROJECT_PLAN.md`固定7里程碑/35任务；详细契约在`docs/spec/`。
